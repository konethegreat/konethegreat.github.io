# Portfolio Flagship: Assets, Verification and Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every case study real visual evidence and a downloadable technical brief, finish per-route metadata, prove the site through an accessibility and link matrix, and ship it.

**Architecture:** A Playwright capture script turns the six live deployments into committed WebP screenshots and a generated data file. A second script renders two-page A4 PDFs from the same case-study data. `src/data/case-media.ts` is the single join between studies, screenshots and briefs. The router owns per-route canonical and social metadata. Verification is automated with Vitest and Playwright, with a small network link checker.

**Tech Stack:** Playwright, sharp, tsx, React 19, Vite 8, Vitest, axe-core, GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-10-30-portfolio-flagship-design.md` (sections 17 to 23)

## Global Constraints

- No em dashes in user-facing copy.
- Light is the default theme; dark is the workshop mode. Every page is checked in both.
- Never invent a metric, screenshot or deployment. A missing screenshot falls back to the existing illustrated cover.
- Screenshots are only of Kone's own deployments. Cite the capture date in the caption.
- Briefs are two A4 pages, generated from the same data as the site, and labelled with their source and October 2026.
- No analytics, cookies or third-party requests.
- Do not publish a CV PDF and do not include Mostoeneng Bill work.
- Rand pricing only after scoping. No invented prices.
- Committed assets live under `public/`; generated TypeScript is marked do-not-edit.
- Every task ends with unit tests, the relevant Playwright spec, and a commit.

```js
import { chromium } from "@playwright/test"
import sharp from "sharp"
import { mkdir, writeFile } from "node:fs/promises"
import path from "node:path"

const captured = "30 October 2026"
const sites = [
  { slug: "sa-jas", url: "https://sajas.pages.dev/" },
  { slug: "clearcut", url: "https://145-241-100-85.sslip.io/" },
  { slug: "munisolve", url: "https://munisolve-za.vercel.app" },
  { slug: "reservoir", url: "https://konethegreat.github.io/reservoir/" },
  { slug: "ui-vault", url: "https://konethegreat.github.io/ui-vault/" },
  { slug: "k-one", url: "https://k-one-it-solutions-website.erictshivhinda.workers.dev/" },
  { slug: "timelex", url: "https://timelex-automated-time-tracking.netlify.app/" },
]
const viewports = {
  desktop: { width: 1440, height: 900 },
  phone: { width: 390, height: 844 },
}

const browser = await chromium.launch()
const results = {}

for (const site of sites) {
  const entry = {}
  for (const [name, viewport] of Object.entries(viewports)) {
    const context = await browser.newContext({ viewport, deviceScaleFactor: 1 })
    const page = await context.newPage()
    try {
      const response = await page.goto(site.url, { waitUntil: "load", timeout: 45_000 })
      if (!response || response.status() >= 400) throw new Error(`HTTP ${response?.status()}`)
      await page.waitForTimeout(2500)
      const png = await page.screenshot({ type: "png" })
      const dir = path.join("public", "shots", site.slug)
      await mkdir(dir, { recursive: true })
      const file = path.join(dir, `${name}.webp`)
      await sharp(png).webp({ quality: 82 }).toFile(file)
      entry[name] = {
        src: `/shots/${site.slug}/${name}.webp`,
        width: viewport.width,
        height: viewport.height,
        captured,
        source: site.url,
      }
      console.log(`captured ${site.slug} ${name}`)
    } catch (error) {
      console.warn(`skipped ${site.slug} ${name}: ${error.message}`)
    } finally {
      await context.close()
    }
  }
  if (entry.desktop) results[site.slug] = entry
}

await browser.close()
const header =
  "// AUTO-GENERATED by scripts/capture-screenshots.mjs. Do not edit by hand.\n" +
  "export interface SiteShot {\n  src: string\n  width: number\n  height: number\n  captured: string\n  source: string\n}\n\n" +
  "export const siteShots: Record<string, { desktop: SiteShot; phone: SiteShot }> = "
await writeFile("src/data/shots.generated.ts", header + JSON.stringify(results, null, 2) + "\n")
console.log(`wrote ${Object.keys(results).length} sites`)
```

```ts
import { siteShots } from "./shots.generated"
import { caseStudies } from "./case-studies"
import { projectBySlug } from "./projects"

export interface CaseImage {
  src: string
  alt: string
  width: number
  height: number
  caption: string
}

export interface CaseMedia {
  cover?: CaseImage
  gallery: CaseImage[]
  technicalBrief: string
  briefSource: string
}

const coverSlugs = ["sa-jas", "clearcut", "munisolve", "reservoir", "ui-vault", "k-one"]
const captured = "30 October 2026"

function coverFor(slug: string): CaseImage | undefined {
  if (!coverSlugs.includes(slug)) return undefined
  const shot = siteShots[slug]?.desktop
  const project = projectBySlug(slug)
  if (!shot || !project) return undefined
  return {
    src: shot.src,
    alt: `${project.title} home page at desktop width.`,
    width: shot.width,
    height: shot.height,
    caption: `Screenshot of the live site, captured ${captured}.`,
  }
}

function galleryFor(slug: string): CaseImage[] {
  const project = projectBySlug(slug)
  const shots = siteShots[slug]
  if (!project || !shots) return []
  if (slug === "timelex") {
    return [
      {
        src: shots.desktop.src,
        alt: "TimeLex v1 prototype dashboard at desktop width.",
        width: shots.desktop.width,
        height: shots.desktop.height,
        caption: `TimeLex v1 prototype, captured ${captured}.`,
      },
      {
        src: shots.phone.src,
        alt: "TimeLex v1 prototype at phone width.",
        width: shots.phone.width,
        height: shots.phone.height,
        caption: `TimeLex v1 prototype on a phone, captured ${captured}.`,
      },
    ]
  }
  if (!coverSlugs.includes(slug)) return []
  return [
    {
      src: shots.phone.src,
      alt: `${project.title} at phone width.`,
      width: shots.phone.width,
      height: shots.phone.height,
      caption: `Phone layout, captured ${captured}.`,
    },
  ]
}

function briefSourceFor(slug: string): string {
  const project = projectBySlug(slug)
  return project?.home === "konethegreat"
    ? "Generated from the public repository, October 2026."
    : "Generated from the project record and published notes, October 2026."
}

export const caseMedia: Record<string, CaseMedia> = Object.fromEntries(
  caseStudies.map((study) => [
    study.slug,
    {
      cover: coverFor(study.slug),
      gallery: galleryFor(study.slug),
      technicalBrief: `/docs/${study.slug}-brief.pdf`,
      briefSource: briefSourceFor(study.slug),
    },
  ]),
)
```

```ts
import { chromium } from "@playwright/test"
import { mkdir, writeFile } from "node:fs/promises"
import { caseStudies } from "../src/data/case-studies"
import { projectBySlug } from "../src/data/projects"

const esc = (value: string) =>
  value.replace(/&/g, "&amp;").replace(/</g, "&lt;").replace(/>/g, "&gt;").replace(/"/g, "&quot;")
const list = (items: string[], limit: number) =>
  items.slice(0, limit).map((item) => `<li>${esc(item)}</li>`).join("")

function prose(study: (typeof caseStudies)[number], heading: string) {
  const section = study.sections.find((s) => s.kind === "prose" && s.heading === heading)
  return section && section.kind === "prose" ? section.body.slice(0, 2) : []
}
function items(study: (typeof caseStudies)[number], heading: string) {
  const section = study.sections.find((s) => s.kind === "list" && s.heading === heading)
  return section && section.kind === "list" ? section.items : []
}

function html(study: (typeof caseStudies)[number]) {
  const project = projectBySlug(study.slug)
  if (!project) throw new Error(`missing project ${study.slug}`)
  const source =
    project.home === "konethegreat"
      ? "Generated from the public repository, October 2026."
      : "Generated from the project record and published notes, October 2026."
  const decisions = (study.decisions ?? [])
    .slice(0, 3)
    .map(
      (d) => `<article><h3>${esc(d.title)}</h3><p><strong>Choice.</strong> ${esc(d.choice)}</p>
      <p><strong>Why.</strong> ${esc(d.why)}</p><p><strong>Trade-off.</strong> ${esc(d.tradeoff)}</p></article>`,
    )
    .join("")
  const problems = prose(study, "The problem").map((p) => `<p>${esc(p)}</p>`).join("")
  return `<!doctype html><html lang="en"><head><meta charset="utf-8"><title>${esc(project.title)} brief</title>
  <style>
    @page { size: A4; margin: 0; }
    * { box-sizing: border-box; }
    body { margin: 0; color: #17140f; font: 10.2pt/1.5 "Segoe UI", Arial, sans-serif; }
    .page { position: relative; width: 210mm; height: 297mm; padding: 17mm 18mm 20mm; page-break-after: always; overflow: hidden; }
    .page:last-child { page-break-after: auto; }
    .bar { position: absolute; inset: 0 0 auto; height: 5mm; background: linear-gradient(90deg, #b7823b, #2f7d75); }
    .eyebrow { margin: 0; font: 8pt/1.4 "Courier New", monospace; letter-spacing: .18em; text-transform: uppercase; color: #7a5a2e; }
    h1 { margin: 6mm 0 2mm; font-size: 30pt; line-height: 1; letter-spacing: -.02em; text-transform: uppercase; }
    .tagline { margin: 0; font: italic 14pt/1.35 Georgia, serif; color: #4a443b; }
    .meta { display: flex; gap: 8mm; margin: 6mm 0 0; padding: 4mm 0; border-top: 1px solid #d9d1c2; border-bottom: 1px solid #d9d1c2; }
    .meta div { font-size: 9pt; }
    .meta span { display: block; font: 7pt/1.4 "Courier New", monospace; letter-spacing: .14em; text-transform: uppercase; color: #7a7368; }
    h2 { margin: 7mm 0 2mm; font-size: 15pt; }
    p { margin: 0 0 2.5mm; }
    ul { margin: 0; padding-left: 5mm; }
    li { margin-bottom: 1.6mm; }
    article { padding: 3mm 0; border-bottom: 1px solid #e6dfd2; }
    article h3 { margin: 0 0 1.5mm; font-size: 11.5pt; }
    .stack { display: flex; flex-wrap: wrap; gap: 2mm; padding: 0; list-style: none; }
    .stack li { margin: 0; padding: 1mm 2mm; border: 1px solid #d9d1c2; border-radius: 2mm; font: 8pt/1.2 "Courier New", monospace; }

    a { color: #2f6d66; text-decoration: none; }
  </style></head><body>
  <section class="page"><div class="bar"></div>
    <p class="eyebrow">Kone Tshivhinda · Technical brief</p>
    <h1>${esc(project.title)}</h1>
    <p class="tagline">${esc(study.tagline)}</p>
    <div class="meta">
      <div><span>Year</span>${esc(study.year)}</div>
      <div><span>Role</span>${esc(study.role)}</div>
      <div><span>Team</span>${esc(study.team)}</div>
```

- [ ] **Step 2: Write the link checker**

```ts
import { caseStudies } from "../src/data/case-studies"
import { projects } from "../src/data/projects"
import { site } from "../src/data/profile"

const urls = new Set<string>([site.url, "https://konethegreat.github.io/sitemap.xml"])
for (const project of projects) for (const link of project.links) urls.add(link.href)
for (const study of caseStudies) urls.add(`${site.url}/work/${study.slug}`)

let failures = 0
await Promise.all(
  [...urls].map(async (url) => {
    try {
      const response = await fetch(url, {
        redirect: "follow",
        signal: AbortSignal.timeout(20_000),
        headers: { "user-agent": "kone-portfolio-link-check" },
      })
      if (response.status >= 400) throw new Error(`HTTP ${response.status}`)
      console.log(`ok   ${response.status} ${url}`)
    } catch (error) {
      failures += 1
      console.error(`fail ${url} ${(error as Error).message}`)
    }
  }),
)
if (failures) process.exit(1)
console.log(`checked ${urls.size} URLs`)
```

Add `"check:links": "tsx scripts/check-links.ts"` to `package.json`.
